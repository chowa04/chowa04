### 03. Otto — Automated Repository Security Scanner

<details>
<summary><strong>View Project Details</strong></summary>

<br/>

Otto is an automated security scanning service that inspects repositories for code vulnerabilities, suggests fixes, and audits network ports and API specifications. It Detects serious and minor security vulnerabilities in source code, provides AI-assisted suggested fixes with one-click pull request generation, Tests exposed network ports and validate OpenAPI endpoints.


### GitHub Integration & PR Comments

To automatically scan pull requests and receive automated review comments with findings and fixes, install the following GitHub App:

[Otto Security App](https://github.com/apps/otto-security)

Use the CLI to generate the workflow file:

```bash
otto setup -e production
```

This writes `.github/workflows/production.yml`. Commit and push this file to your repository. When any pull request is opened or updated, Otto triggers a scan and posts review comments.

**Repository:** [Otto GitHub Repo](https://github.com/349gill/otto)

</details>
